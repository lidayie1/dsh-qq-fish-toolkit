## 3. 脚本干不了的部分（视频里最花时间的就是这些）

**A. 重启加载**
装完必须完全退出再打开，插件才生效。

**B. B 站养鱼（第 3 步）**
- 设置 → 养鱼 → 填人设 + 你的 **B 站 UID**
- 用**小号**扫码登录。默认配置是给新号做的保守值：评论监听关闭、请求间隔 1500ms、每日写操作上限 30 次 —— **别调高**，这些不是保守，是保命
- 点「依赖体检」，哪项报错把原文贴给 DSH 让它处理

**C. QQ（第 5 步）**
需要 NapCat，视频给的是夸克网盘里的第三方包（页面上那个链接和我后来在别处搜到的还不是同一个，说明这东西在到处转手）。做法：解压 → 跑 `launcher.bat` → 控制台会打印带 token 的 WebUI 地址 → 浏览器打开用**小号**扫码 → 在 WebUI 里建「外部客户端」网络配置（重连间隔 3000ms）→ 再让 DSH 去连。
私人消息没回复 → 把该会话权限改成「完全权限」（**只改这一个会话，别全局**）。

**D. 表情包 / 人格卡**
表情包文件夹路径告诉 DSH 让它接上；人格卡可以让它自己起草，你改完再应用。

## 4. 视频没强调、但你得知道的几件事

**① 它让你全程给「完全权限」——这是这套教程最值得警惕的地方。**
评论区 91 赞的那条（发帖人自己在做插件安全向的内容）说得很直接：演示里"报错就丢给 AI 自己修"很顺滑，但等于把改机器的权力交出去了——修的过程要装什么、改什么，全由它定；而"能拦住它的从来不是提示词，是权限"。我的建议：**按需授权**，每次审批看清楚它要干什么，尤其涉及 `Remove-Item`、写注册表、装全局包、改 PATH 的操作。

**② 这是半个引流视频。**
UP 主置顶评论就是推某宝的付费代做 / Ae 课程。命令和配置本身是真的、有用；"做不出来去买课"那层可以忽略。

**③ 「养鱼」这步失败率不低。**
UP 主置顶下面第一条回复就是"养鱼那步卡住了"，115 赞。装不上先别怀疑自己，去看仓库 issue：<https://github.com/Alterssss/dsh-bili-whale/issues>（当前 23 个 open）。

**④ 第三方包 = 供应链风险。**
NapCat 走第三方 QQ 协议（封号风险），安装包在网盘（来源不可验证）；`dsh-bili-whale` / `dsh-speak-up` 是个人仓库，装进来就有文件读写 + 执行命令的权限。真要用，用小号、单独的用户目录，别在存了重要东西的主力账户上试。

**⑤ 回滚很简单。**
脚本跑之前备份了 `package.json`（`package.json.bak-<时间>`）。出问题就把它盖回去、重启，或者删掉 `dependencies` 里对应的包再重启。

## 7. ffmpeg 最后是怎么装上的（3 分钟，可复用）

直连 gyan.dev 只有 3–4 KB/s（114MB 要 9 小时），npmmirror / GitHub / 各家 GitHub 代理全挂。真正的解法是**换包**：

`imageio-ffmpeg` 这个 PyPI 包本身就是「ffmpeg.exe 的轮子」，而**阿里云 PyPI 镜像在国内是满速的**。

```powershell
# ① 镜像 200 OK 只要 0.3 秒，实测 595 KB/s
curl.exe -sS --ssl-no-revoke -o tools\imageio_ffmpeg.whl `
  https://mirrors.aliyun.com/pypi/packages/e5/55/1d50cdd78d862a30c2ce44f01cea387f77b364b21fa2fecf1590258b215b/imageio_ffmpeg-0.7.0-py3-none-win_amd64.whl
# ② 校验（与 PyPI 索引里的 sha256 一致才算数）
#    7a22b45f60321d4172bdf2bc61f716bce4c81b85727bd59c7c7e371055a6a440
# ③ .whl 就是 zip，直接抽 ffmpeg.exe
Add-Type -AssemblyName System.IO.Compression.FileSystem
$z = [IO.Compression.ZipFile]::OpenRead('tools\imageio_ffmpeg.whl')
$e = $z.Entries | ? { $_.FullName -match 'ffmpeg-win-x86_64.*\.exe$' }
[IO.Compression.ZipFileExtensions]::ExtractToFile($e, "$env:USERPROFILE\.dsh\bili-whale\bin\ffmpeg.exe", $true)
$z.Dispose()
```

结果：31.2MB / 50 秒 / 622 KB/s，拿到 `ffmpeg 7.1-essentials_build`（gyan 的 GPL 构建，就是原来要下 9 小时那个）。

**为什么放 `~\.dsh\bili-whale\bin\`**：`tools\lib\ffmpeg.mjs` 的查找顺序是 `$FFMPEG` → PATH → `<仓库>/bin` → `~\.dsh\bili-whale\bin` → 剪映。PATH 得重启 DSH 才生效，而这个目录**当场就生效**，不用重启；同时也在 `tools\ffmpeg\bin\` 放了一份给以后的终端会话用。
